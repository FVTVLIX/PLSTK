# More room to arrange your edit

PLSTK now scrolls the timeline when you move a clip or trim a visual clip near either horizontal edge. The closer you move to the edge, the faster it scrolls. Extra working room appears as you continue along the timeline.

Visual clips, titles, images, and independent audio clips keep their position under the pointer as the view scrolls. Snapping and source limits continue to apply. Release to make one undoable edit, or press Escape to cancel. Switching away from the app, hiding the timeline, or changing zoom also cancels an active drag.

This update includes eight navigation and native scrolling tests. All 63 tests pass. The project format remains version 8, so no new migration is needed.
